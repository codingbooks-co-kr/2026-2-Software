## **오픈소스소프트웨어 GitHub 활동 증빙**
(1) 자신의 비공개 Repository에 해당 주차의 과제를 Commit하고 Push합니다.  
(2) GitHub에서 과제의 Commit History를 복사합니다.  
(3) https://github.com/codingbooks-co-kr --> 2026-2-Software --> Discussion에 들어가 댓글에 복사한 Commit History를 붙여넣습니다.

※ Commit History 캡처 이외 이름/학번/전화번호/이메일 등 개인정보가 표시되지 않도록 합니다.   
※ 실제 소스코드를 올리지 않습니다.
