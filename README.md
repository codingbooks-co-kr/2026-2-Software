# 2026 2학기 오픈소스소프트웨어 과제

## 과제 업로드 학생 안내 가이드

1. 이 폴더(`weekOO`)에 OO주차 과제 코드를 저장합니다.

2. **Commit:** GitHub Desktop에서 변경된 파일을 확인 --> Commit 메시지에 `OO주차 과제 제출` 입력 --> **Commit to main**을 클릭합니다.

3. **Push:** `Push origin`을 클릭하여 GitHub에 업로드합니다.

4. **과제 수정:** 같은 방법으로 다시 Commit하고 Push합니다. 수정할 때 Commit 메시지는 `OO주차 과제 수정`으로 합니다.

5. **제출 확인:** GitHub의 Commit History에서 확인할 수 있습니다.
